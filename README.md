# Schuijers' Webstack

A modular web tooling and component ecosystem for modern front-end projects.

## Agent guidance

- Keep the root [`AGENTS.md`](AGENTS.md) generic and monorepo-wide.
- Add workspace-specific guidance in local files such as `packages/<name>/AGENTS.md` or `apps/<name>/AGENTS.md`.
- Use [`templates/AGENTS.workspace.template.md`](templates/AGENTS.workspace.template.md) as the starting point for new
  workspace guides.
- Update the root `AGENTS.md` only when a policy should apply to all workspaces.
